# 사진 기반 3D 연결 계획

**Goal:** 사진 설비에 생성된 메시를 연결하고 확인된 치수와 배치를 유지한다.
**Architecture:** 기존 Worker 파일 검증과 import-dialog를 재사용한다. 기존 구성요소 하나의 meshId만 변경하고 사진·위치·치수·검토 이력을 유지한다. 자동 생성 엔진은 외부 전송 여부에 대한 답변과 실행 환경 확보 후 연결한다.
**Tech Stack:** TypeScript, Three.js, Node 기본 테스트, 기존 Playwright 점검.

## 실행 순서

- [x] `prepareMesh`에 명시적 목표 치수를 지원한다. 축 변환·정규화는 그대로 사용하고 목표 치수는 유한한 정수 1~100000만 받는다. 단위 없는 생성 모델도 보정할 수 있게 한다.
- [x] 기존 가져오기 대화상자에 연결 모드를 추가한다. 대상의 폭·깊이·높이를 표시하고 공장 선택과 원본 단위를 숨긴다. 실패 시 닫지 않고 오류를 표시한다.
- [x] 선택 설비에 구성요소 선택 및 3D 연결 버튼을 추가한다. 선택 대상을 ID로 고정하고 기존 검토 이력과 자료 출처를 보존한다. 전체 기계 모델은 본체 등 해당 범위의 구성요소를 선택해야 한다고 알린다.
- [x] 임의 단위 메시 보정·잘못된 치수·퇴화 형상 테스트와 브라우저 연결/되돌리기/복원 점검을 실행한다.

## 자동 생성 엔진의 현재 제약

현재 GPU는 Radeon RX 560 약 4GB이며 로컬 생성 모델 실행을 검증하지 못했다. 외부 서비스는 사용자 선택, 계정/API 키 및 사진 전송 동의가 필요하다. 외부 전송이나 과금은 아직 실행하지 않는다. 수동 파일 연결을 자동 생성 완료로 표현하지 않는다.
