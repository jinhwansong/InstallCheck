# 로컬 3D 가져오기 구현·검증

2026-09-10: GLB/STL/OBJ를 설치된 Three.js 로더로 읽어 정적 메시로 배치한다. 새 의존성이나 외부 업로드 API는 추가하지 않았다. 단위와 상향 축은 사용자가 확인한다. 실제 정밀 형상 충돌 대신 기존 외곽 상자 검사 규칙을 적용하며 화면과 검토서에 한계를 표시한다.

메시는 정규화 좌표로 프로젝트에 한 번 보존하고 구성요소와 검사 스냅샷이 ID로 참조한다. JSON 복원 시 좌표 범위, 전체 크기, 참조 무결성을 검사한다. 기존 schema 1 자료는 계속 읽는다. 파일 크기·면 수 한도와 Worker 시간 제한을 두고 GLB 외부 리소스는 거부한다.

검증: Node 기본 테스트 러너 15개 통과. OBJ 단위/상향 축, ASCII STL, 바이너리 GLB, 외부 참조 거부, JSON/이력 메시 참조를 포함한다. Edge 실제 브라우저에서 샘플 OBJ 업로드, 치수 확인, 설비 추가, 검사 저장, 새로고침 복원, 빈 파일 오류, 모바일 가로 넘침 없음, 외부 네트워크 요청 없음 확인. 기존 배치/되돌리기/이력/JSON/인쇄 브라우저 회귀 검사도 통과했다.

다양한 제조사 CAD 파일 전체 호환성을 검증한 것은 아니다. STEP/DWG, 사진 생성, 정밀 삼각형 간섭, 텍스처·애니메이션과 서버 보안은 이번 범위에 없다.
